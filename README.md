# Netflix Movies and TV Shows EDA

## About the Project
In this project, I performed Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. I explored the data to understand different trends and patterns in Netflix content.

## Dataset
I used the Netflix dataset from Kaggle.

Dataset link: https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Checked the dataset rows, columns, and data types.
- Analyzed missing values.
- Calculated summary statistics.
- Compared movies and TV shows.
- Analyzed content ratings and release years.
- Created graphs to understand the data.
- Identified some interesting findings.

## Conclusion
This project helped me learn how to analyze real-world data using Python and create visualizations to understand the results.
